Create an HTML/CSS website based on two documents in /Coding/D479:
1. The wireframe SVG, D479\ Wireframe.svg
2. The About the Island doc that provides copy to be used on each page.

The SVG contains wireframes for every page on the website. Create a layout that matches the wireframe layout, including dummy images where the placeholder images are and text where appropriately-sized rectangles are. 

Specific design guidance:
1. At the bottom of the home page, there are a series of placeholder images along with text echoing the nav links, followed by placeholder text rectangles. These should be made into card components with drop shadows, which "hover" slightly when moused over. The title text ("Lodging", "Dining" etc) should appear just below the image, above the text copy.

2. Create a tasteful tropical color palette of blue, green, and orange for the website. Use green for the nav bar background, blue for the hero background on the home page, and orange for h1s on each page.

3. Use the About the Island document to inform the copy of the website, verbatim, on each page. For example, the Lodging page will only have the exact copy provided in the Lodging section of the document. For most pages aside from the home page, the page will consist of a Title ("Lodging"), an image to the right, then another section below that with an image to the left and the appropriate page copy to that image's right side. For the homepage, the copy will be in the center of the page, just below the hero section, center-justified.
